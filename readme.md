## 📖 Sobre o Projeto

O **GeoMundo** é uma aplicação web educativa desenvolvida com o objetivo de tornar o aprendizado de **Geografia** mais dinâmico, visual e divertido.

A plataforma utiliza conceitos de **gamificação** para transformar conteúdos geográficos em desafios interativos. O jogador pode responder perguntas, acumular XP, manter sequências de acertos, avançar de nível e explorar diferentes regiões do mundo através de um mapa interativo.

O projeto também foi desenvolvido como uma forma prática de aplicar conhecimentos de **desenvolvimento web, JavaScript, manipulação do DOM, modularização, JSON, armazenamento local e integração com bibliotecas externas**.

---

## 🎯 Objetivo

O principal objetivo do GeoMundo é unir **educação e tecnologia**, criando uma experiência que incentive o aprendizado de Geografia através de elementos presentes nos jogos.

A proposta é transformar o estudo tradicional em uma experiência baseada em:

- 🌎 Exploração
- 🧠 Conhecimento
- 🎮 Desafios
- ⭐ Progressão
- 🔥 Sequências de acertos
- 🏆 Competição
- 📚 Aprendizado

---

## ✨ Funcionalidades

### 🎮 Quiz Interativo

O jogador participa de desafios de Geografia através de perguntas com alternativas.

O sistema trabalha com:

- Perguntas;
- Respostas corretas;
- Respostas incorretas;
- Vidas;
- Pontuação;
- Sequência de acertos;
- Dicas;
- Progressão.

---

### ⭐ Sistema de XP

O jogador recebe experiência ao responder corretamente às perguntas.

O XP representa a evolução do jogador dentro da plataforma.
